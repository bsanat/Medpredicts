# M2-v4. Подбор тренировочного веса при САД ≥150

22.11.2026 · Сравнение четырёх множителей для пятипризнакового TabM на NHANES 2017–март 2020. Для выбора использовались три fold только внутри исходного train. В каждом fold модель с рецептом MLP v2 переобучалась с отдельной частью для ранней остановки. TabM использовал ту же часть для подгонки, 80 эпох и три совпадающих seed на вариант. Метрики рассчитывались с исходными весами NHANES по объединённым внеобучающим строкам. [Протокол](../protocols/m2-v4-weight-grid.md)

## Выбор на кросс-валидации

По одному внеобучающему предсказанию на участника для каждого seed. Всего 2 324 участника, из них 198 с САД ≥150, по 66 на fold. В таблице средние по трём seed, MAE и смещение в мм рт. ст.

| Модель | Общая MAE | Δ общей MAE | MAE при САД ≥150 | Снижение относительно v2 | Смещение при САД <110 |
|---|---:|---:|---:|---:|---:|
| MLP по рецепту v2 | 10,74 | — | 34,47 | — | +12,55 |
| TabM 2× | 11,11 | +0,37 | 34,07 | 1,17% | +11,70 |
| TabM 4× | 11,68 | +0,94 | 30,69 | 10,97% | +13,10 |
| TabM 6× | 12,35 | +1,61 | 27,90 | 19,07% | +14,30 |
| TabM 8× | 13,15 | +2,41 | 25,51 | 26,00% | +15,21 |

Только 2× прошёл ограничение общей MAE ≤v2 +0,50. Этот множитель зафиксирован перед повторной проверкой на прежней validation. При 8× достигнуто снижение на 25% в верхней группе, но выросли общая ошибка и завышение при САД <110. Ни один множитель на кросс-валидации не прошёл оба условия.

## Повторная проверка на прежней validation

Обучение на всём исходном train из 2 324 человек. Оценка на 497 участниках, из них 39 с САД ≥150. Для TabM показано среднее по пяти seed.

| Модель | Общая MAE | Δ общей MAE к v2 | MAE при САД ≥150 | Снижение относительно v2 | Seed, прошедшие оба условия |
|---|---:|---:|---:|---:|---:|
| Опубликованный v2 ONNX | 10,34 | — | 34,32 | — | — |
| TabM 2× | 10,43 | +0,09 | 32,47 | 5,39% | 0/5 |
| TabM 4× | 10,71 | +0,37 | 28,13 | 18,04% | 0/5 |

Повторный запуск воспроизвёл результаты предыдущего 4× сравнения для всех seed. Для достижения 25% на этой выборке требовалась MAE ≤25,74 в группе САД ≥150. У 4× более сильный эффект на прежней validation, а на кросс-валидации его рост общей MAE вышел за лимит. Подбор одного множителя в проверенном диапазоне не дал устойчивого совместного улучшения. Внешняя когорта не использована. Модель приложения — v2.

## Воспроизведение

Из `ml-ai/` используйте `.venv`, изолированные зависимости и рабочий каталог из [первого пилота](m2-v4-pilot.md#воспроизведение).

```sh
PYTHONPATH="$pilot/packages" .venv/bin/python research/m2_v4_weight_grid.py \
  --workspace "$pilot" --output "$pilot/m2_v4_weight_grid.json"
```
