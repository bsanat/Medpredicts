# M2-v4. Сравнение TabM и MLP с весом 4×

Этот протокол зафиксирован локально до запусков, 22.11.2026. Задача, пять признаков, исходы, участники, веса обследования и правила включения совпадают с [пилотом](m2-v4-pilot.md). Используются только прежние train и validation. Тестовые циклы исключены.

- Сравниваем замороженный v2 ONNX, MLP `5→64→64→1` и TabM с двумя блоками шириной 64 и восемью выходами. У обеих обучаемых моделей ReLU, dropout 0,1, Smooth L1 с переходом в 8 мм рт. ст. и AdamW (шаг 0,003, decay 0,01). Каждая обучается 80 эпох с batch 128 без ранней остановки на CPU. В TabM потери усредняются по выходам, при предсказании усредняются сами выходы.
- Умножаем fasting weight в train на 4 при измеренном САД ≥150. Делим полученные веса на их среднее и используем их для нормализации признаков, цели и функции потерь. Для MAE обеих моделей и v2 используем исходные fasting weights validation.
- Заранее заданные seed — 2026, 2027, 2028, 2029, 2030. Одинаковый порядок батчей внутри каждой пары обеспечивается выделенным генератором, который не зависит от инициализации модели и dropout. Поэтому даже прогон с seed 2026 может отличаться от первоначального пилота. Сравнение не уравнивает число параметров.
- Публикуем общую MAE и MAE в группе фактического САД ≥150 для всех seed. Основной итог по каждой архитектуре — среднее пяти MAE, дополнительно выборочное стандартное отклонение и число seed, прошедших пороги. Среднее вычисляется по метрикам отдельных моделей. Успех по группе — MAE ≤75% от v2. Ограничение общей ошибки — MAE ≤v2 + 0,5 мм рт. ст. Проверяем оба условия для среднего и каждого seed. Validation используется для исследовательского сравнения. Разброс по seed описывает чувствительность к обучению, а не статистическую неопределённость по участникам.
