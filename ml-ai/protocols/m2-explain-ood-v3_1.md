# Дополнение v3.1: локальные объяснения и предупреждение о нетипичном вводе

**Статус: зарегистрировано 22.11.2026 до вычисления любых объяснений, расстояний или порогов.** Модель `MedPredict-SBP-mlp-v2` и её ONNX-байты не меняются. Протокол v3 (внешняя проверка, интервал) остаётся в силе.

## 1. Локальное объяснение каждого ответа

- **Метод:** точные baseline-значения Шепли (Shapley) по пяти входам. Для подмножества S признаков v(S) = f(x_S, r_{¬S}), где отсутствующие признаки заменены опорной точкой r. φ_i = Σ_{S ⊆ N∖{i}} |S|!(5−|S|−1)!/5! · [v(S∪{i}) − v(S)]. Все 2⁵ = 32 комбинации считаются одним батчем ONNX; аппроксимаций нет.
- **Опорная точка r:** взвешенные (`WTSAFPRP`) средние пяти признаков на train v2. Для пола это доля женщин (число между 0 и 1); это допустимая точка отсчёта для графа, но не категория человека.
- **Свойство:** Σφ_i = f(x) − f(r) с точностью float32. Python и Java должны совпадать на синтетических эталонах с допуском 0,01 мм рт. ст.
- **Интерпретация:** вклад описывает поведение модели относительно среднего участника обучающей выборки. Это **не** причинное влияние фактора на давление и не рекомендация менять показатель. Коррелированные признаки (возраст, глюкоза, ИМТ) делают разложение неоднозначным.
- **Глобальная сводка (описательно):** среднее |φ_i| на validation v2. Не используется для выбора или изменения модели.

## 2. Предупреждение о нетипичной комбинации входов (OOD)

- **Метод:** квадрат расстояния Махаланобиса d² = (x − μ)ᵀ Σ⁻¹ (x − μ), где μ и Σ — невзвешенные среднее и ковариация пяти признаков на train v2.
- **Порог (правило зафиксировано заранее):** 99-й перцентиль d² на validation v2. Train и test v2 и внешняя когорта для выбора порога не используются.
- Ввод с d² выше порога принимается, но ответ получает код `OUT_OF_DISTRIBUTION`, и интерфейс показывает предупреждение. Оценка не скрывается и не подменяется.
- Границы полей API (одномерный диапазон train) остаются отдельной проверкой.

## 3. Описательный анализ на внешней когорте NHANES 2021–2023

Внешние данные уже открыты по v3, поэтому анализ здесь только описательный и не меняет порог:
- доля помеченных участников;
- weighted MAE и signed bias для помеченных и непомеченных;
- покрытие 90% интервала из v3 для помеченных и непомеченных.

Ожидание, записанное заранее: у помеченных ошибка выше, а покрытие ниже. Если это не подтвердится, предупреждение остаётся (оно сообщает о нетипичности, а не о точности), а результат публикуется как есть.
