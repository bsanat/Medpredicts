# AI-ассистент MedPredict

Ассистент объясняет поля, единицы, функции приложения, результат и ограничения модели — **только** по утверждённой базе знаний с указанием источника. Он отделён от прогноза: не считает и не меняет оценку, не ставит диагнозы, не советует лечение, при экстренных симптомах направляет на 103/112. Рекомендация научного руководителя (MED-55).

## Как устроено
- База знаний: [`../backend/src/main/resources/assistant/knowledge-base.json`](../backend/src/main/resources/assistant/knowledge-base.json) — 28 записей, у каждой исходный документ проекта.
- Backend: `kz.medpredict.assistant` — `POST /api/v1/assistant/messages`, `GET /api/v1/assistant/status`; Google Gemini через REST со структурированным JSON `{answer, sources, refused}`; ответ без валидного источника заменяется отказом; лимит запросов в минуту; промпты, ответы и ключ не логируются.
- Frontend: страница `#/assistant`, кнопка «Объяснить с помощью ассистента» передаёт только числа результата (без исходных показателей).
- Ключ: `GEMINI_API_KEY` в git-игнорируемом `backend/.env` (шаблон `backend/.env.example`).

**Отклонения и оговорки:**

- Модель — бесплатная `gemini-3.5-flash-lite` (A-v1.1) вместо `gemini-3.5-flash` из-за дневного лимита бесплатного тарифа.
- Автоматические метрики не проверяют каждое утверждение; поэтому сделан ручной обзор. Набор составлен командой и мог быть легче реальных вопросов пользователей — проверка с пользователями в [плане 1](../plans/01-user-study.md).
- На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов: не вводите персональные данные.
