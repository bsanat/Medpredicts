# План 2. Высокое давление: эксперимент M2-v4

**Проблема:** при фактическом САД ≥150 модель v2 систематически занижает оценку (внешняя MAE около 36, интервал верен только в 26% случаев).

**Цель:** снизить ошибку в группе ≥150 хотя бы на 25% без ухудшения общей MAE, проверив это на ещё не использованных данных.

## Протокол (зарегистрировать до обучения: `ml-ai/protocols/m2-v4.md`)
- **Обучение:** NHANES 2017–2020 (как в v2) и, по решению команды, 2021–2023. Данные 2021–2023 уже открыты, поэтому их можно использовать только для обучения, а не для итоговой проверки.
- **Итоговая проверка:** не тронутые циклы, например NHANES 2015–2016. Там давление мерили ртутным тонометром: это различие методов записать как ограничение и оценить отдельно.
- **Основная метрика:** weighted MAE в группе ≥150; вторичные: общая MAE, bias по диапазонам, покрытие интервала.
- **Правило успеха:** снижение MAE ≥150 на 25% или больше с 95% интервалом бутстрепа, общая MAE не хуже v2 + 0,5.

## Кандидаты (по одному изменению, у каждого свой эксперимент)
1. Новые признаки из NHANES: окружность талии, HbA1c, креатинин, курение, физическая активность.
2. Функции потерь: Huber, quantile (медиана + квантили), взвешивание по диапазону давления.
3. Модели: gradient boosting (LightGBM/CatBoost), FT-Transformer или TabM (нейросеть для таблиц — по теме диплома).
4. Условный conformal-интервал (Mondrian по предсказанному диапазону) — для покрытия при высоком давлении.

## Решение о внедрении
Новые признаки — это новые поля в форме, то есть больше работы пользователю. Внедрять только при явном выигрыше. Если улучшения нет, это честный отрицательный результат и отдельный раздел диплома.
